Sobre o projeto

Nascido da necessidade real do IFSul

O EduSchedule surgiu da observação de dificuldades enfrentadas em instituições de ensino, onde atendimentos ainda são agendados por mensagens, e-mails e comunicação presencial dispersa.

Nossa missão

Simplificar a relação entre alunos e professores

Acreditamos que o tempo dos professores e alunos é valioso demais para ser gasto em troca de mensagens e busca por horários disponíveis. O EduSchedule centraliza tudo em um único lugar, com transparência e organização.

A plataforma atende instituições de todos os tamanhos: desde pequenas escolas técnicas até grandes universidades com múltiplos campi, oferecendo um ambiente exclusivo para cada escola dentro do ecossistema.

Nossos valores

O que guia cada decisão do EduSchedule

🎯

Foco no usuário

Cada funcionalidade é pensada para reduzir o atrito e facilitar a vida de alunos, professores e administradores.

🔒

Privacidade por design

Dados de cada escola são isolados. Nenhum administrador acessa informações de outra instituição.

⚡

Simplicidade radical

Se precisar de manual para usar, está errado. A interface é intuitiva o suficiente para qualquer perfil de usuário.

🌱

Crescimento sustentável

Planos escaláveis que acompanham o crescimento da instituição, sem cobranças surpresa.

Tecnologia

Arquitetura MVC pensada para escalar

O EduSchedule é desenvolvido seguindo o padrão MVC com PHP no backend, MySQL como banco de dados e um frontend moderno em HTML, CSS e JavaScript puro.

View Interface do usuário

HTML semântico, CSS modular e JavaScript sem frameworks. Consome a API e exibe dados dinamicamente.

Controller Lógica de negócio

Recebe requisições, valida dados, orquestra o fluxo e retorna respostas em JSON.

Model Acesso a dados

Concentra as consultas SQL com prepared statements para segurança máxima.
